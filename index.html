⚡ LiteSlider
Lightweight & Accessible JavaScript Slider

Simple. Fast. Accessible.

LiteSlider is a lightweight JavaScript library that creates accessible sliders and carousels using native CSS scroll-snap and minimal vanilla JavaScript. No dependencies, no bloat, just smooth scrolling functionality.

🪶 Lightweight

Minimal footprint with no dependencies. Fast loading and excellent performance.

♿ Accessible

Built with accessibility in mind. Semantic markup and keyboard navigation support.

🎨 CSS Scroll-Snap

Leverages native browser features for smooth, performant scrolling behavior.

🚀 Easy to Use

Simple API and minimal configuration. Just call slider() and you're done.

📱 Responsive

Works seamlessly across all devices and screen sizes.

⚡ No Dependencies

Pure vanilla JavaScript. No jQuery or other libraries required.
